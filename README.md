# 🎊好想玩云原神🎊 —云原神梗插件> "啊😲？云朵☁️😄，哒↘哒↗哒↘哒↗哒↘，好想玩原神😨……"

一个 AstrBot插件，自动检测「云朵」「云原神」等关键词并回复经典云原神梗，内置 **11段随机变体**不刷屏，支持手动指令、关键词管理、**群聊黑/白名单**。

---

## ✨功能|功能 |说明 |
|------|------|
| 🎯 **关键词自动触发** |检测到消息中含「云朵」「云原神」等关键词时自动回复 |
| 🎲 **11段随机池** |每次随机取一段，长版拆短不刷屏 |
| 👋 **先打招呼** |触发后先发「欸，云朵」，延迟后再发梗段 →制造节奏感 |
| 💬 **手动命令** |输入 `/云原神`或 `/cloudys`随时玩梗 |
| 🔧 **关键词管理** |管理员可通过命令动态增删自定义触发关键词 |
| 🚫 **群聊黑/白名单** |支持黑名单模式（指定群不触发）和白名单模式（仅指定群触发） |
| ⚙️ **面板配置** |支持在 AstrBot管理面板中调整触发开关、延迟、额外关键词、黑名单模式与群列表 |

## ⚙️配置说明在 AstrBot管理面板 →插件配置中找到 `好想玩云原神🎊`可调节：

|配置项 |类型 |默认值 |说明 |
|--------|------|--------|------|
| `enable_keyword_trigger` | bool | `true` |是否启用关键词自动触发，关闭后只有手动 `/云原神`有效 |
| `trigger_keywords` | list | `["云朵", "云原神"]` | **触发关键词列表**，消息中含列表中任意词即触发，可自由增删 |
| `reply_delay_ms` | int | `800` |发送「欸，云朵」后延迟多少毫秒再发梗段 |
| `blacklist_mode` | string | `blacklist` |群聊名单模式：`blacklist`（黑名单中的群不触发）/ `whitelist`（仅名单中的群触发） |
| `blacklist_groups` | list | `[]` |群聊黑/白名单列表，填写群号（字符串），可通过管理命令动态增删 |

> 💡群名单支持 **两种途径**管理：
>1.面板配置 `blacklist_groups` —适合首次批量设置>2.命令 `/云原神管理 blacklist add/remove` —适合动态调整，持久化保存---

## ⚠️注意事项-关键词自动触发只对非命令消息生效（以 `/`或 `#`开头的消息不会被触发）
- **所有关键词都在 `trigger_keywords`配置中管理**，管理面板直接增删，没有"不可删除"的硬编码关键词-私聊消息不受黑/白名单影响（始终可触发）
- `blacklist_groups`配置项与通过管理命令添加的群号是 **独立存储 +合并生效**的- `enable_keyword_trigger`关闭后所有关键词自动触发失效，但不影响手动 `/云原神`命令-第二条梗段使用后台独立任务发送，与群内其他消息完全隔离，不受事件处理器生命周期限制---
