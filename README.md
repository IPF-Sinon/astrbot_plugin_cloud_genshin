# 🎊 好想玩云原神🎊 v2.0 — 云原神梗插件

> "啊😲？云朵☁️😄，哒↘哒↗哒↘哒↗哒↘，好想玩原神😨……"

一个 AstrBot 插件，自动检测关键词并回复经典云原神梗，内置 **可配置梗段词库** 随机发送不刷屏。**v2.0 全面升级**：所有关键词统一管理、管理命令可直接修改首次回复词和梗段词库、修改即时生效无需重载插件！

---

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 🎯 **关键词自动触发** | 检测到消息中含触发关键词时自动回复 |
| 🎲 **梗段随机池** | 每次随机取一段，不刷屏 |
| 👋 **先打招呼** | 触发后先发首次回复词，延迟后再发梗段 → 制造节奏感 |
| 💬 **手动命令** | 输入 `/云原神` 或 `/cloudys` 随时玩梗 |
| 🔧 **管理命令全部搞定** | 用命令管理关键词、首次回复词、梗段词库、黑/白名单，修改即生效 |
| 🚫 **群聊黑/白名单** | 支持黑名单模式（指定群不触发）和白名单模式（仅指定群触发） |
| ⚙️ **面板配置初始值** | 管理面板配置作为首次安装时的初始值，启动后完全由管理命令接管 |

## 📦 安装

### 方式一：ZIP 安装（推荐）
1. 将 `astrbot_plugin_cloud_genshin.zip` 上传到 AstrBot
2. 在 AstrBot 管理面板 → 插件管理 → 安装插件 → 选择 ZIP 文件
3. 启用插件即可

### 方式二：手动放置
将 `astrbot_plugin_cloud_genshin/` 整个文件夹复制到 AstrBot 的 `addons/` 目录下，重启 AstrBot。

## ⚙️ 配置说明

AstrBot 管理面板中的配置项 **仅在首次安装时作为初始默认值**。插件启动后，所有可配置项（关键词、首次回复词、梗段词库、群名单）都由管理命令控制，修改即时生效并自动保存。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_keyword_trigger` | bool | `true` | 是否启用关键词自动触发，关闭后只有手动 `/云原神` 有效 |
| `reply_delay_ms` | int | `800` | 发送首次回复词后延迟多少毫秒再发梗段 |
| `blacklist_mode` | string | `blacklist` | 群聊名单模式：`blacklist`（黑名单中的群不触发）/ `whitelist`（仅名单中的群触发） |
| `trigger_keywords` | list | `["云朵", "云原神"]` | 初始触发关键词，启动后由管理命令接管 |
| `first_reply` | string | `"欸，云朵"` | 初始首次回复词，启动后由管理命令接管 |
| `quote_pool` | list | 11段梗 | 初始梗段词库，启动后由管理命令接管 |

> 💡 **一键起飞**：面板配置只读一次，之后全部靠命令！
> `/云原神管理 status` 可随时查看当前生效的全部配置

## ⚠️ 注意事项

- 关键词自动触发只对非命令消息生效（以 `/` 或 `#` 开头的消息不会被触发）
- **所有关键词、首次回复词、梗段词库、群名单** 都可以通过管理命令修改，修改即时生效并持久化
- 私聊消息不受黑/白名单影响（始终可触发）
- `enable_keyword_trigger` 关闭后所有关键词自动触发失效，但不影响手动 `/云原神` 命令
- 第二条梗段使用后台独立任务发送，与群内其他消息完全隔离，不受事件处理器生命周期限制
- 从旧版升级的用户：首次启动会自动合并旧的自定义关键词文件到新的统一 `data.json`
